# Chatbot WebApp

A modern, interactive chatbot web application built with Python backend and HTML/CSS frontend.

## Overview

This project is a full-stack chatbot application that combines a responsive web interface with a powerful Python backend to deliver an intelligent conversational experience. The application features a clean, user-friendly interface and robust server-side processing.

## Technology Stack

- **Frontend:** HTML, CSS (62.2%)
  - Responsive web interface
  - Interactive UI components
  - Modern styling and design

- **Backend:** Python (37.8%)
  - Server-side logic and processing
  - Chatbot intelligence and response handling
  - Data processing and API management

## Getting Started

### Prerequisites

- Python 3.7+
- A modern web browser
- Git

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dheerajsaroha/chatbot-webapp.git
   cd chatbot-webapp
   ```

2. **Set up Python environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

### Running the Application

1. **Start the backend server:**
   ```bash
   python app.py
   ```

2. **Open the application:**
   - Navigate to `http://localhost:5000` (or your configured port) in your web browser

## Usage

1. Open the chatbot interface in your browser
2. Type your message in the input field
3. Press Enter or click Send to submit your message
4. View the chatbot's response in the conversation window
5. Continue the conversation as needed
